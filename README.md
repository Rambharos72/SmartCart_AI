# SmartCart_AI
SmartCart AI
Smarter Shopping, Simplified.

SmartCart AI is an e-commerce web application designed to make online
shopping more convenient through product discovery, category-based
browsing, cart management, and rule-based product recommendations.
Overview
The project demonstrates a full-stack shopping experience with a
React-based frontend, PHP REST APIs, and an SQLite database. Its
recommendation feature uses local rule-based matching rather than an
external AI service. The checkout flow is intended for demonstration and
does not process real payments.
Features
- User registration and sign-in
- Product catalogue and product browsing
- Category-based product discovery
- Rule-based product recommendations
- Shopping cart management
- Delivery details management
- Demo checkout and order receipt
- Backend communication through PHP REST APIs
- SQLite database integration
- Responsive user interface
Technology Stack

  Frontend                        React.js, JavaScript, HTML5, CSS3, Bootstrap

Important Notes
- Recommendations: The current recommendation feature uses local
  rule-based matching. It is not connected to an external AI model or
  AI API.
- Payments: Checkout is a demonstration flow. No real payment
  gateway or live payment processing is claimed.
- OTP: Any OTP verification included in the project is for local
  demonstration purposes.
- Database: The project uses SQLite.
